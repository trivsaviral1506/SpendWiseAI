# SpendWise AI

SpendWise AI is a smart expense management application built using the MERN stack.

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt
- CORS

## Current Features

- Backend REST API
- MongoDB database integration
- User model
- User registration API
- Password hashing with bcrypt
- Authentication architecture

## Planned Features

- JWT authentication
- Expense management
- Expense analytics
- Smart financial insights
- Trie-based search
- Stack-based undo functionality
- Queue-based recent transactions
- Max Heap for top expenses
- AI-powered financial recommendations
